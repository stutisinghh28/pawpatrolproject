🏗️ System Architecture

PawPatrol is designed as a cloud-native, serverless architecture built on Amazon Web Services:

  • Frontend: Responsive Single-Page Application (HTML5, CSS3, Vanilla ES6+ JS) with Leaflet OpenStreetMap.
  • Compute Layer: AWS Lambda running Python 3.14 on x86_64 architecture.
  • Database Layer: Amazon DynamoDB (NoSQL) for high-speed sub-millisecond retrieval. Table: PawPatrol-Reports.
  • Photo Storage: Amazon S3 with secure pre-signed PUT URLs. Zero public bucket risk!
  • Emergency Broadcast: Amazon SNS (Simple Notification Service) for real-time volunteer SMS/email dispatches on Critical/High triage.
  • Automated Follow-ups: Amazon EventBridge Scheduler for periodic verification of unresolved cases.
